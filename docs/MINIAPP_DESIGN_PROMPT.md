## РОЛЬ

Ты — продуктовый дизайнер, специализирующийся на Telegram Mini Apps и финтех-интерфейсах.
Спроектируй и свёрстай кликабельный HTML-прототип Telegram Mini App для банковского
AI-ассистента Asakabank (Узбекистан). Прототип должен выглядеть как настоящее мини-приложение
внутри Telegram, а не как обычный веб-сайт.

## КОНТЕКСТ ПРОДУКТА

Сейчас продукт живёт как Telegram-бот на aiogram + LangGraph-агент (GPT-4o-mini) + FastAPI + PostgreSQL.
Пользователь общается текстом, бот отвечает сообщениями и reply-клавиатурами. Мы переносим этот
опыт в Mini App: сохраняем чат с AI, но всё, что сегодня «нарисовано» кнопками и текстом
в сообщениях, превращаем в нормальные экраны.

**Аудитория:** розничные клиенты банка в Узбекистане, массовый сегмент, телефоны средне-бюджетные,
интернет нестабильный. Три языка интерфейса: **русский (основной), узбекский, английский**.
Валюта — узбекский сум (UZS), суммы большие (например 350 000 000 сум), формат разрядов обязателен.

**Что умеет ассистент сегодня (это и есть функциональный охват дизайна):**

1. **Чат с AI-агентом** — свободные вопросы по банку, поиск по базе FAQ (гибридный поиск:
   лексика + эмбеддинги). Агент возвращает текст + набор быстрых ответов (chips).
2. **Каталог продуктов** — 7 категорий:
   - 🏠 Ипотека, 🚗 Автокредит, 💰 Микрозайм, 🎓 Образовательный кредит
   - 💳 Вклад (депозит), 💳 Дебетовая карта, 💳 Валютная карта
3. **Квалификация до показа продуктов** (короткий опросник-дерево, фильтрует выдачу):
   - Автокредит: официальная зарплата? → зарплатная карта Asaka / другого банка → марка авто (GM/UzAuto или иная)
   - Ипотека: официальный доход? → самозанятый? → рынок: первичка / вторичка / ремонт
   - Микрозайм: доход → зарплатная карта → канал оформления: в ЦБУ / онлайн
   - Вклад: цель (копить / снимать частично) → валюта (UZS / USD / EUR)
   - Тупиковые ветки: «подходящих предложений нет» / «рассмотрите другие продукты»
4. **Карточка продукта** — ставка (или диапазон ставок), срок, сумма, первоначальный взнос,
   обеспечение, цель кредита; для вклада — таблица «валюта × срок × ставка», пополнение,
   частичное снятие, порядок выплаты процентов; для карты — платёжная система (Uzcard/Humo/Visa/
   Mastercard), валюта, стоимость выпуска и обслуживания, кэшбэк, срок действия, доставка/самовывоз.
   Ставка динамическая: зависит от возраста / суммы / срока / первоначального взноса / типа дохода —
   в интерфейсе нужен способ показать «от 18% до 26%» и почему.
5. **Калькулятор**:
   - Кредит: сумма → срок → первоначальный взнос → (иногда возраст) → ежемесячный платёж,
     переплата, итог, **график погашения** (сегодня отдаётся PDF — в Mini App нужна таблица + кнопка «Скачать PDF»)
   - Вклад: сумма → срок → доход к концу срока / ежемесячный доход
6. **Заявка (лид)** — после расчёта: «Хотите, мы вам перезвоним?» → имя → телефон → подтверждение.
7. **Отделения** — три типа объектов с разным набором услуг:
   - 🏦 Филиал (ЦБУ) — полный спектр услуг, есть ориентир и ссылка на карту
   - 🏪 Офис продаж (мини-офис) — физлица, без юрлиц
   - 🚗 Точка продаж (в автосалонах) — только автокредиты, консультация, банкомат
   Нужны: список с фильтром по типу, поиск по городу/названию, «найти ближайшее» по геолокации,
   карточка отделения (адрес, ориентир, телефон, часы работы, кнопка «Маршрут»), экран
   «чем отличаются типы отделений» (матрица услуг).
8. **Курсы валют** — данные ЦБ РУз, 10 валют (USD, EUR, RUB, GBP, KZT, CNY, JPY, CHF, TRY, KRW)
   с флагами и изменением к прошлому дню. Подразделы «курс юрлиц / онлайн-конверсии / банкоматов»
   пока в статусе «скоро».
9. **Живой оператор** — передача диалога человеку. Состояния: «ищем свободного оператора»,
   «оператор подключился», «все операторы заняты», «оператор не ответил — возвращаю к боту»,
   «чат работает с 8:00 до 23:00 (Ташкент)», «требуется номер телефона». Оператор может прислать
   фото/файл. После завершения — оценка работы оператора от 1 до 5.
10. **Полезные ссылки** — мобильное приложение (Android/iOS), соцсети (Instagram, Telegram-канал,
    Facebook, сайт), контакты: линия доверия +998 71 200 55 22, колл-центр 1152.
11. **Настройки** — язык (ru/en/uz), номер телефона, история текущей сессии, завершить диалог.
12. **Онбординг** — при первом запуске: выбор языка → запрос номера телефона (нативный Telegram-запрос
    контакта) → приветствие с дисклеймером: «бот работает в тестовом режиме и может ошибаться,
    для точной информации обратитесь к оператору или в колл-центр 1152».

## ЧТО НУЖНО СПРОЕКТИРОВАТЬ

Кликабельный прототип со следующими экранами (минимум):

**Онбординг:** 1) выбор языка, 2) запрос номера телефона, 3) приветствие / первый экран.

**Главный экран (Home):** приветствие по имени из Telegram, крупный вход в чат с ассистентом,
плитки категорий продуктов, виджет курсов валют (2–3 валюты + «все курсы»), быстрый доступ
к отделениям, точка входа к оператору.

**Чат:** лента сообщений (пользователь / ассистент / оператор — визуально различимые),
индикатор набора, чипы быстрых ответов под последним сообщением ассистента, поле ввода
с кнопками «прикрепить» и «голос», системные плашки («вы переключены на оператора», «сессия
закрыта из-за неактивности», «достигнут дневной лимит сообщений»), состояние ожидания оператора.
Внутри чата ассистент может присылать **богатые карточки**: список продуктов, карточку отделения,
результат расчёта, PDF-график — покажи, как они выглядят в ленте.

**Продукты:** список категорий → опросник квалификации (1 вопрос на экран, прогресс, кнопка «назад»,
возможность задать вопрос ассистенту прямо из опросника) → список подходящих продуктов
→ карточка продукта → калькулятор → результат расчёта с графиком → форма заявки → успех.
Обязательно нарисуй пустое состояние: «под ваши параметры предложений не нашлось».

**Отделения:** список с сегмент-контролом по типам, поиск, «рядом со мной», карточка отделения,
экран сравнения типов отделений.

**Курсы валют:** таблица/список с флагами, изменением, датой обновления; блок «скоро» для
недоступных разделов.

**Прочее:** полезные ссылки, настройки, история сессии, экран оценки (1–5 звёзд) + комментарий.

## ПЛАТФОРМЕННЫЕ ОГРАНИЧЕНИЯ TELEGRAM MINI APP (соблюдать строго)

- Прототип живёт в вебвью Telegram: ширина ~390pt, высота ~844pt, **сверху хедер Telegram**,
  снизу — системная область. Нарисуй прототип в рамке телефона с имитацией хедера Telegram.
- Тема берётся из `themeParams`: `bg_color`, `text_color`, `hint_color`, `link_color`,
  `button_color`, `button_text_color`, `secondary_bg_color`, `section_bg_color`,
  `section_header_text_color`, `subtitle_text_color`, `destructive_text_color`, `accent_text_color`.
  **Все цвета в макете — CSS-переменные с фолбэком**, чтобы приложение подхватывало тему пользователя.
  Обязательно покажи и светлую, и тёмную тему (переключатель в прототипе).
- Используются нативные элементы Telegram, не рисуй их веб-аналоги внутри контента:
  - `BackButton` — навигация назад (в хедере Telegram, не свой «← Назад» вверху экрана)
  - `MainButton` — главное действие экрана, прилипшее к низу (например «Рассчитать платёж»,
    «Отправить заявку»), с состояниями: активна, неактивна, загрузка (спиннер)
  - `SecondaryButton` — второстепенное действие рядом с main
  - `HapticFeedback` — отклик на выборы и подтверждения (опиши, где именно)
  - `requestContact` — запрос телефона, `openLink` / `openTelegramLink` — внешние ссылки
- Учитывай safe-area insets и то, что при открытой клавиатуре высота вьюпорта уменьшается
  (`viewportStableHeight`) — экран чата не должен ломаться.
- Никакой собственной нижней таб-бар-навигации «как в iOS» без необходимости: если делаешь табы —
  обоснуй и держи их компактными (Telegram уже отъедает вертикаль).
- Один палец, большой палец: основные действия — в нижней трети экрана, тап-таргеты ≥ 44pt.

## ДИЗАЙН-СИСТЕМА

Сначала выведи **дизайн-токены** (отдельная секция в прототипе), потом экраны:

- **Цвет:** нейтральная база из темы Telegram + фирменный акцент банка. Фирменный цвет вынеси
  в отдельный токен `--brand` (по умолчанию — глубокий синий; в проде уточняется по гайдлайну
  Asakabank). Семантика: success (одобрено/выгодно), warning (внимание), danger (ошибка/отказ),
  info. Ставки, суммы и «выгода» — акцентно, но без кричащих градиентов.
- **Типографика:** системный шрифт Telegram (SF Pro / Roboto), шкала 12/14/16/20/28/34,
  табличные цифры для сумм и ставок. Учти, что **узбекские строки на 20–40% длиннее русских**,
  а английские — короче: кнопки и заголовки не должны ломаться (покажи хотя бы один экран
  во всех трёх языках).
- **Компоненты:** карточка продукта, строка списка с иконкой, чип быстрого ответа, пузырь
  сообщения (3 вида), поле ввода суммы с форматированием разрядов и подсказкой границ
  («от 10 000 000 до 500 000 000 сум»), слайдер срока с пресетами (12 / 24 / 36 / 60 мес),
  сегмент-контрол, аккордеон условий, таблица графика платежей, банер-дисклеймер,
  скелетоны загрузки, пустые состояния, состояние ошибки сети, тост.
- **Иконки:** линейные, один вес. Эмодзи из бота (🏠 🚗 💰 💳 🏦 📍) можно заменить на нормальные
  иконки — покажи соответствие.
- **Доступность:** контраст ≥ 4.5:1 в обеих темах, не полагайся только на цвет
  (например «ставка выросла/снизилась» — цвет + стрелка + знак).

## КРАЕВЫЕ СЛУЧАИ, КОТОРЫЕ НАДО ПОКАЗАТЬ

- Ассистент не нашёл ответ → предложение переключиться на оператора
- Дневной лимит сообщений исчерпан
- Операторы недоступны / нерабочее время (8:00–23:00 Ташкент)
- Пустой результат подбора продуктов
- Введена сумма вне допустимых границ продукта (мягкая коррекция, а не красная ошибка)
- Долгий ответ AI (> 3 сек) — что видит пользователь
- Оффлайн / потеря соединения в момент чата с оператором

## ФОРМАТ РЕЗУЛЬТАТА

Один самодостаточный HTML-артефакт (инлайн CSS и JS, без внешних CDN, шрифтов и картинок —
иконки инлайн-SVG, иллюстрации — CSS/SVG):

1. **Обложка**: название, задача, ключевые решения в 5 пунктах.
2. **Дизайн-токены**: палитра (light/dark), типографическая шкала, отступы, радиусы, тени.
3. **Библиотека компонентов**: каждый компонент во всех состояниях (default / hover-press /
   disabled / loading / error).
4. **Экраны**: в рамке телефона 390×844, сгруппированы по флоу, каждый экран подписан
   (название + что здесь главное действие + какие нативные кнопки Telegram задействованы).
5. **Кликабельный демо-режим**: 3 сквозных сценария, которые реально кликаются —
   (а) «Хочу автокредит»: онбординг → квалификация → продукт → расчёт → заявка,
   (б) «Найти ближайшее отделение»,
   (в) «Вопрос ассистенту → не помог → оператор → оценка».
6. **Переключатели** вверху: светлая/тёмная тема, язык ru/uz/en (хотя бы для главного экрана,
   чата и карточки продукта).
7. **Заметки для разработки**: какие данные приходят с бэкенда на каждом экране,
   какие состояния грузятся асинхронно, где нужен дебаунс/скелетон.

## КРИТЕРИИ ПРИЁМКИ

- Экран не выглядит «сайтом в вебвью»: используется хедер Telegram, MainButton внизу, BackButton вместо своей навигации.
- Любую сумму и ставку можно прочитать одним взглядом; разряды отформатированы.
- Флоу «квалификация → продукт → расчёт → заявка» проходится не более чем за 7 тапов после выбора категории.
- Чат остаётся первоклассным гражданином, а не вкладкой «на всякий случай».
- Прототип одинаково читаем в светлой и тёмной теме и не разъезжается на узбекском языке.

Начни с краткого (не больше 10 строк) описания концепции и структуры навигации, задай мне
**максимум 3 уточняющих вопроса, если они реально меняют дизайн**, и сразу переходи к артефакту.
