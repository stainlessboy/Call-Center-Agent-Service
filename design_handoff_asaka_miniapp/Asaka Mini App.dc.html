AI-ассистент банка в Telegram Mini App

Переносим текущего бота (aiogram + LangGraph) в мини-приложение: чат остаётся ядром продукта, а всё, что сегодня собрано из reply-клавиатур и текста в сообщениях, становится полноценными экранами — каталог, квалификация, калькулятор, заявка, отделения, курсы, оператор.

01
Чат — первый экран, не вкладка
Ассистент отвечает богатыми карточками прямо в ленте: продукты, расчёт, отделение, PDF-график.
02
Нативные элементы Telegram
BackButton вместо своей навигации, MainButton внизу, SecondaryButton, requestContact, haptics.
03
Квалификация = 1 вопрос на экран
Категория → 3 вопроса → подбор → расчёт → заявка укладывается в 7 тапов, с выходом в чат на любом шаге.
04
Деньги читаются с одного взгляда
Табличные цифры, разряды через пробел, диапазон ставки с объяснением «от чего зависит».
05
Тема и язык — из системы
Красный Asakabank поверх нейтралей Telegram; все цвета — переменные themeParams с фолбэками, ru / uz / en с запасом на длину узбекских строк.

Заметки для разработки

Данные по экранам
Home: initData (имя, язык), GET /rates/top?n=3 (кэш 15 мин), GET /products/categories (кэш сутки), GET /branches/nearest — только после разрешения геолокации.
Чат: WS /chat (или SSE) — токены ответа стримом; POST /chat/message; чипы приходят вместе с ответом агента (quick_replies[]); rich-карточки — типизированный payload (product_list, calc_result, branch_card, file).
Квалификация: GET /qualify/<product>/tree один раз, ветвление на клиенте; ответы шлём в POST /qualify/result → список product_id.
Калькулятор: POST /calc (сумма, срок, взнос, возраст, product_id) с дебаунсом 400 мс; ставка приходит с бэкенда — не считаем на клиенте. График — POST /calc/schedule (таблица) и GET /calc/schedule.pdf.
Заявка: POST /leads {product_id, calc_id, name, phone} → номер заявки; идемпотентность по client_request_id.
Отделения: GET /branches?type=&q=&lat=&lon= — пагинация по 20, статичный map-тайл с бэкенда.
Оператор: WS-события queue_position, agent_joined, agent_left, timeout, out_of_hours; POST /operator/rating.
Асинхронность, скелетоны, дебаунс
Курсы и список продуктов рендерим из кэша мгновенно, обновляем в фоне (stale-while-revalidate).
Ответ ассистента > 800 мс → индикатор набора; > 3 с → скелетон-пузырь с подписью «ищу в базе знаний».
Поиск отделений — дебаунс 300 мс, минимум 2 символа; геолокация — только по тапу.
Калькулятор — дебаунс 400 мс, оптимистичный локальный аннуитет и уточнение с сервера.
Отправка заявки — MainButton.showProgress(), блокировка полей, повтор по кнопке при сетевой ошибке.
Оффлайн — очередь сообщений в CloudStorage, автоотправка при восстановлении сети.
Платформа
Тема: подписка на themeChanged, все цвета — CSS-переменные с фолбэком; проверяем оба режима.
Клавиатура: слушаем viewportChanged, лента чата и MainButton пересчитываются по viewportStableHeight.
Навигация: единый стек экранов, BackButton.show()/hide() по глубине; закрытие приложения — только с корня.
Haptics: selectionChanged на выборах и слайдерах, impactOccurred('light') на MainButton, notificationOccurred на успехе/ошибке.
Safe-area: нижний отступ 22 px + env(safe-area-inset-bottom).
Языки: ru / uz / en в одном бандле, uz — самые длинные строки, все кнопки тянутся по высоте.
Открытые вопросы
Точные фирменные цвета и логотип Asakabank — сейчас в макете плейсхолдер --brand.
Продуктовые линейки и ставки — из брифа; перед разработкой сверить с актуальным тарифным справочником.
Нужна ли авторизация по номеру (SMS) для просмотра истории заявок или достаточно Telegram-идентификации.
Электронная очередь и выходные дни отделений — вне текущего объёма («скоро»).
